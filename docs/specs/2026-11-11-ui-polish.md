# 2026-11-11 — Chỉnh UI/UX (đợt 1)

## 1. Context / Why
Giao diện còn thô (mặc định egui, nhãn tiếng Anh lẫn Việt, Dashboard là đoạn chữ dài).

## 2. Decision
Giữ egui; thêm lớp theme + vài thành phần dùng chung thay vì viết lại từng trang. Màu sáng/tối theo hệ điều hành.
Đợt này chỉ làm: theme, thanh điều hướng, Tổng quan, nút chính, trạng thái rỗng. Các trang Nhóm/Nhập-Xuất/Ứng dụng/Cài đặt/Chẩn đoán chỉ hưởng theme (chưa bố cục lại).

## 3. Design
`ui/lib.rs`: `ACCENT`, `apply_theme` (thang chữ 22/14.5/12, spacing 8, nút padding 12×6, bo góc 6, màu chọn), `primary_button`, `card`, `status_pill`.
`ui/main_view.rs`: sidebar 150px (tên + trạng thái + mục tiếng Việt), Tổng quan dạng card (trạng thái + nút bật/tắt, cảnh báo có hành động, 3 bước dùng, bảng phím tắt),
empty state cho danh sách/biên tập mẫu, nút "Lưu"/"+ Mẫu mới" là nút chính. `ui/form.rs`: nút Chèn màu nhấn. `app/orchestrator.rs`: gọi `apply_theme`.

## 4. API / Schema changes
Thêm hàm public trong `zs_ui` (không phá vỡ). Không đổi config/schema.

## 5. How to test
Mở app: kiểm tra sidebar, thẻ Tổng quan, chuyển sáng/tối của Windows, cửa sổ nhỏ (~900×600) không bị cắt, chữ có dấu. `cargo test --workspace` pass.
**Chưa quan sát bằng mắt trong phiên này** (không chụp được màn hình).
